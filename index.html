玩法说明

基本流程：54 张牌，三人各 17 张，留 3 张底牌。依次叫分（1/2/3 分），叫分最高者成为地主并获得底牌。

牌型：单张、对子、三张、三带一、三带二、顺子（≥5 张连牌）、连对（≥3 对）、飞机、飞机带翅膀、四带二、炸弹（四张相同）、王炸（大小王）。

大小：3 < 4 < … < 10 < J < Q < K < A < 2 < 小王 < 大王。炸弹可压任意非炸弹牌型，王炸最大。

计分：底分 × 倍数。每出一次炸弹/王炸倍数 ×2，春天（地主一手未出完农民即出完）倍数 ×2。地主胜则赢两家的分，农民胜则两家各赢地主的分。
